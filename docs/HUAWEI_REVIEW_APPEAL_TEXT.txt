Dear Huawei AppGallery Review Team,

BitLut is a production Android application that transfers real fitness data from Huawei Health to Android Health Connect.

Package name:
com.openhealth.sync

Requested Huawei Health Kit permissions:
- Step read
- Distance read
- Activity read
- Activity record read
- Historical data open week

The app does not generate fake health data, mock steps, mock workouts, mock calories, or placeholder records.

Current test flow:
1. Install the signed release APK.
2. Install or update HMS Core.
3. Install or update Huawei Health.
4. Sign in to Huawei Health.
5. Ensure Huawei Health contains real step/activity data.
6. Open BitLut.
7. Grant Android Health Connect permissions.
8. Tap Huawei Health.
9. Approve Huawei Health Kit permissions.
10. Tap Sync.

Current blocker:
Huawei Health shows BitLut as connected, but Huawei Health Kit DataController.read() returns 50005 on step data.

Please verify Health Kit access for this app, package name, release SHA-256 and the requested scopes.
