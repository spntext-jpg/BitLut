# UI Expressive Final Sprint

This sprint changes presentation only. It does not modify HuaweiHealthManager, SyncWorker, GoogleHealthManager, or Health Connect permissions.

## Product tabs

- Summary: hero KPI, steps, sleep, heart rate, rings, recent sessions.
- History: 7-day trend cards with sparklines and trend arrows.
- Settings: Google Health Connect, Huawei Health, manual sync, last sync, Health Kit status.

## Visual language

- Apple Health-inspired light cards over #F2F2F7 system background.
- Material 3 Expressive rounded cards, 28-34dp radius.
- Glassmorphic layers and soft glowing category accents.
- Dark mode remains supported by the existing palette and system theme.

## Guardrails

- Sync/backend files are intentionally untouched.
- RU/EN localization must remain complete.
- Patch scripts and .bak files must never be committed.
